Qué es

El problema que resuelve

Cuando la información vive repartida en muchas bases de datos — una por bodega, una por sucursal, una por sistema — responder una pregunta simple ("¿cuánto inventario tenemos de este producto en todas las tiendas?") significa entrar a cada base por separado, correr la misma consulta N veces y juntar los resultados a mano.

Faro elimina ese paso manual: se registra cada base de datos una sola vez, se agrupan libremente como tenga sentido para el negocio (por región, por marca, por lo que sea — o simplemente sin agrupar), y desde ahí una sola consulta SQL puede correr contra una base o contra todas las seleccionadas a la vez, trayendo los resultados ya combinados y marcados con su origen.

Es una herramienta para quien ya sabe SQL — un analista, un desarrollador, un administrador de TI — no un generador de reportes para usuario final. Piensa en algo como SSMS o pgAdmin, pero pensado desde cero para trabajar con muchas bases de datos de golpe.

Navegación

Cómo está organizada

Todo vive alrededor de un único árbol de navegación al lado izquierdo — sin pestañas de menú que recorrer, todo a un clic.

Árbol de servidores y bases de datos

Cada base de datos registrada aparece ahí, agrupada libremente en "servidores" (agrupadores opcionales, se arma arrastrando) o suelta en "Sin grupo". Buscador arriba, selección de una o varias bases con un clic.

Editor de consulta + resultados

El panel principal: escribe la consulta arriba, corre con F5, resultados combinados abajo. Redimensionable arrastrando la línea divisoria.

Pestañas y ventanas adicionales

Para trabajar varias consultas al mismo tiempo — pestañas dentro de la misma ventana, o abrir una base en una ventana de Windows completamente aparte.

Historial, Favoritos y Apariencia

Tres paneles accesibles con un ícono, que se abren encima del árbol sin perder de vista la consulta activa.

Funcionalidad

Qué se puede hacer hoy

Conexión

PostgreSQL y SQL Server

Cada base de datos elige su propio motor, host y credenciales — sin importar cómo esté agrupada. Las contraseñas se guardan cifradas en el almacén seguro de Windows, nunca en texto plano.

Organización

Agrupación 100% libre

Un "servidor" en Faro es solo una etiqueta que tú decides — arrastra y suelta bases de datos entre grupos, o déjalas sueltas. Nunca obliga a que compartan esquema ni servidor físico real.

Consulta

Individual o masiva

Modo "Individual" para trabajar sobre una base a la vez; modo "Masiva" para seleccionar cualquier combinación y correr la misma consulta en todas, con los resultados combinados e identificados por origen e IP.

Editor SQL

Pensado para escribir SQL de verdad

Resaltado de sintaxis, autocompletado de tablas y columnas, buscador (Ctrl+F), zoom, formateo automático, números de línea, y detecta automáticamente qué instrucción ejecutar según dónde esté el cursor.

Seguridad

Solo lectura por base de datos

Cada base de datos se marca como "Solo lectura" o "Consultas sin restricciones" de forma independiente — una consulta que modifica datos se bloquea automáticamente en las que están protegidas, con confirmación explícita para desactivarlo.

Resultados

Pensados para volumen real

Tabla de resultados que aguanta cientos de miles de filas sin trabarse, paginación bajo demanda, exportar a CSV con un clic, e importar CSV masivamente respetando el tipo real de cada columna.

Explorador de esquema

Tablas, vistas, funciones, procedimientos

Navega el catálogo de cada base de datos y genera automáticamente el script SELECT, UPDATE o CREATE de cualquier objeto con un clic derecho — sin tener que escribirlo a mano.

Historial y favoritos

Nada se pierde al cerrar la app

Cada consulta ejecutada queda en el historial (persistente, no solo de la sesión), y cualquier consulta se puede guardar como favorita para reusarla después con un clic.

Tecnología

Cómo corre

Faro es una aplicación de escritorio nativa de Windows — un solo .exe, sin necesidad de navegador, sin servidor intermedio que mantener. Se conecta directo a cada base de datos con drivers nativos (PostgreSQL y SQL Server), así que el rendimiento de las consultas es el mismo que tendría cualquier otra herramienta de administración — Faro no agrega ninguna capa extra en medio.

Construida con Flutter, lo que le da una interfaz consistente, fluida y fácil de seguir extendiendo con nuevas funciones a futuro.
